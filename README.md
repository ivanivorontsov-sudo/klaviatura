# Клавиатура (для Ивана)
Основа — HeliBoard 4.2 (GPL-3.0, лицензии сохранены: LICENSE, LICENSE-Apache-2.0, LICENSE-CC-BY-SA-4.0).
Изменения: тёплые мягкие тёмная/светлая темы (не чистый чёрный/белый), рамки клавиш, вибрация по умолчанию, следование системной теме, свой applicationId, только arm64.

## Несколько языков сразу (русский + английский)
Настройки → Языки → Русский → «Дополнительные языки» → English. Тогда на одной раскладке подсказки и свайп
идут по обоим словарям, язык определяется для каждого слова. Переключение раскладки — кнопка-глобус или свайп по пробелу; на пробеле видно текущий язык.

## Свайп (версия 1.1.0+)
Работает сразу, без закрытых библиотек: свой открытый декодер (`app/src/main/java/ru/klaviatura/glide`), словари ru ≈48 тыс. и en ≈47 тыс. слов (FrequencyWords, CC-BY-SA-4.0).
- Учитываются старт и финиш жеста; если жест начат на глобусе/пробеле/Shift, «подлёт» к первой букве отбрасывается (тест «Наши»: `app/src/test/java/ru/klaviatura/GlideDecoderTest.kt`).
- Предлагаются слова и другой раскладки (QWERTY-жест на ЙЦУКЕН → английское слово в кандидатах, и наоборот).
- Обучение только на телефоне: новые слова, вес выбранных, пары слов (следующее слово), поправка на манеру жеста; долгое нажатие на подсказку — «забыть». Экспорт/импорт: Настройки → Жесты.
- Библиотеку Google можно подключить как раньше и выключить «Свой свайп-декодер».

## Голос (офлайн, Vosk)
Микрофон на клавиатуре запускает встроенное офлайн-распознавание. При первом нажатии скачивается модель (~45 МБ, ru или en): прогресс в % на кнопке микрофона (полоска) и в уведомлении (% и МБ из общего), затем «Распаковка…»; при ошибке — понятная причина и кнопка «Повторить».
Язык = текущая раскладка (подписан на кнопке микрофона), смена раскладки сразу меняет язык голоса; голос раскладку не меняет и текст другой азбукой не вставляет.
Текст ставится у курсора, уже набранное не трогается. «Смешанный голос ru+en» — отдельный переключатель (лучший из двух распознавателей по каждой фразе).
Голосовая пунктуация: «точка», «запятая», «вопросительный знак», «новая строка». Можно вернуть системный голосовой ввод выключив «Встроенный офлайн-голос».
Whisper пока не встроен (тяжело для клавиатуры).

## Фон
Внешний вид → фоновое изображение (из файла/галереи) + ползунки «Размытие» и «Затемнение».
«ИИ-фон через веб-чат»: Qwen, ChatGPT, Gemini, Grok, Алиса, Copilot, Шедеврум прямо внутри приложения (вход запоминается, без API). Кнопка «Промпт» вставляет запрос со
 спокойным фоном в нужных пропорциях; готовая картинка подхватывается сама, обрезается под клавиатуру, сжимается, показывается превью → «Применить».
