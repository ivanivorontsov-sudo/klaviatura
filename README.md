Изменения: тёплые мягкие тёмная/светлая темы (не чистый чёрный/белый), рамки клавиш, вибрация по умолчанию, следование системной теме, свой applicationId, только arm64.

## Все возможности (1.3.0)
- **Свайп** — свой открытый декодер: RU+EN одновременно, 840 тыс. словоформ, контекстная модель (биграммы), обучение на телефоне, «буквальная» догадка для новых слов, исправление посреди жеста (задержка или возврат к началу) — теперь со вспышкой следа и вибрацией.
- **Заглавные по контексту**: имена/города во всех падежах; имена-слова («Вера», «Надежда», «Роза», «Слава», «Роман»…) — с заглавной только после «привет», «позвони», «тёте», «уважаемая» и т. п.
- **Голос офлайн**: Zipformer (sherpa-onnx) по умолчанию, Vosk запасной, смешанный ru+en, голосовая пунктуация, заглавные.
- **Эмодзи**: подсказки эмодзи по слову (кот → 🐱, ~30 тыс. русских форм, ~7 тыс. английских; выключается в «Внешний вид»), открываются на «Недавних», ввод нескольких эмодзи одним скольжением (задержать палец и вести).
- **GIF**: кнопка «GIF» в панели эмодзи — поиск KLIPY по слову у курсора, быстрые темы, популярное; вставка картинкой (commitContent) или через буфер. Нужен бесплатный ключ KLIPY (в сборке из секрета или свой в настройках).
- **Буфер обмена**: постоянная история с миниатюрами картинок, буфер перечитывается при каждом открытии клавиатуры, вставка картинкой; опция «Скриншоты в буфер» — свежий скриншот (до 10 мин) сам попадает в историю (нужен доступ к фото).
- **Фон**: из галереи (размытие, затемнение); «Сгенерировать фон» — поле промпта, генерация Pollinations без ключа или через веб-чат (Qwen, ChatGPT, Gemini…) в фоне, превью, «Ещё вариант», применить к дневной/ночной/обеим темам; «ИИ-фон через веб-чат».
- «Сбросить тему» (Внешний вид): стандартные тема и цвета, без фоновых картинок, размытия и затемнения — с подтверждением.
- Тёплые темы, следование системной теме, смена языка свайпом по пробелу, только arm64.

## Что нового в 1.4.0
- **Исправлен вылет** при нажатии на значок смайлов в верхней панели (повторное открытие панели смайлов/GIF). Добавлен тест.
- **Скриншоты и картинки из буфера** теперь видны маленькой миниатюрой над клавиатурой (в строке подсказок). Нажатие вставляет картинку в поле, если приложение это поддерживает. Скриншоты попадают в историю буфера. Если нет доступа к фото, клавиатура иногда напомнит выдать его.
- **Смайлы свайпом:** проведите пальцем по нескольким смайлам, и каждый будет введён.
- **Главные кнопки всегда на панели:** буфер, смайлы и микрофон закреплены по умолчанию. При обновлении они добавляются один раз, остальные ваши настройки панели сохраняются.
- **Слова через дефис свайпом:** где-то, как-то, почему-то, кое-что, из-за, по-моему, well-known, e-mail и другие. Дефис ставится сам.
- **Новый декодер свайпа:** учитывается порядок клавиш и форма траектории. Синтетический тест (2090 свайпов с имитацией неточного пальца, RU+EN): точность первой подсказки выросла с 68,9% до 88,9%, попадание в тройку — с 79,3% до 97,3%.
- **Английская раскладка для программистов:** символы долгим нажатием (q → \`, w → ~, e → =, r → ^, t → {, y → }, u → [, i → ], o → <, p → >, h → |, j → \\, k → %). В словарь добавлены слова из программирования (const, lambda, namespace, async…).
- **Свайп для польского и других языков:** польский, украинский, немецкий, чешский, французский, испанский, итальянский, португальский, нидерландский, шведский, турецкий, болгарский, румынский, венгерский, греческий. Буквы с диакритикой (ą, ł, ż…) распознаются и при свайпе через основную букву (a, l, z). Можно включить несколько языков сразу.
- **Голосовой ввод больше не обрывается на паузах:** запись продолжается, пока вы молчите меньше заданного времени (по умолчанию 20 с; ползунок «Голос: остановка после тишины» в настройках «Непрерывный ввод», можно выбрать «только кнопкой микрофона»). Короткие паузы между фразами только завершают фразу.
- **«Фон с ИИ» — один понятный экран вместо двух пунктов.** Опишите картинку и выберите, чем рисовать: Pollinations (бесплатно, без входа; русский запрос переводится автоматически) или ваш чат (Qwen, ChatGPT, Gemini и др.). Для чата один раз войдите кнопкой «Войти». Дальше запрос вставляется и отправляется сам, готовая картинка забирается, обрезается под клавиатуру, сжимается и показывается в предпросмотре. Её можно применить к светлой и/или тёмной теме. «Показать чат» открывает окно чата, если сайт просит что-то нажать.

## Голос (офлайн, Vosk)
Микрофон на клавиатуре запускает встроенное офлайн-распознавание. При первом нажатии скачивается модель (~45 МБ, ru или en): прогресс в % на кнопке микрофона (полоска) и в уведомлении (% и МБ из общего), затем «Распаковка…»; при ошибке — понятная причина и кнопка «Повторить».
Язык = текущая раскладка (подписан на кнопке микрофона), смена раскладки сразу меняет язык голоса; голос раскладку не меняет и текст другой азбукой не вставляет.
Текст ставится у курсора, уже набранное не трогается. «Смешанный голос ru+en» — отдельный переключатель (лучший из двух распознавателей по каждой фразе).
Голосовая пунктуация: «точка», «запятая», «вопросительный знак», «новая строка». Можно вернуть системный голосовой ввод выключив «Встроенный офлайн-голос».
Whisper пока не встроен (тяжело для клавиатуры).

## Фон
Внешний вид → фоновое изображение (из файла/галереи) + ползунки «Размытие» и «Затемнение».
«ИИ-фон через веб-чат»: Qwen, ChatGPT, Gemini, Grok, Алиса, Copilot, Шедеврум прямо внутри приложения (вход запоминается, без API). Кнопка «Промпт» вставляет запрос со
 спокойным фоном в нужных пропорциях; готовая картинка подхватывается сама, обрезается под клавиатуру, сжимается, показывается превью → «Применить».
