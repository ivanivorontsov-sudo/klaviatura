Klaviatura built-in animated stickers
======================================

The 12 GIF assets in this directory are original artwork made for Klaviatura.
They are dedicated to the public domain under CC0 1.0 Universal.

You may copy, modify, redistribute, and use these files commercially without
permission or attribution. The GIF pack is bundled in the APK, so the panel
works offline and does not require a third-party API key.
